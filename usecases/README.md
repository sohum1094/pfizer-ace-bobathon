# Lab Prompts — IBM ACE + MQ Advanced Labs

Each file in this folder contains **ready-to-paste prompts** for use with an AI assistant
(IBM Bob, ChatGPT, Copilot, etc.) while working through the corresponding advanced lab.

Prompts are grouped into three tiers per lab:

| Tier | Purpose |
|---|---|
| 🔵 **Conceptual** | Understand the theory before building |
| 🟡 **Implementation** | Get hands-on code, config, or ESQL help |
| 🔴 **Troubleshooting** | Diagnose errors and debug running flows |

## How to Use

1. Open the prompt file for the lab you are currently working on.
2. Copy the prompt that matches your current task or question.
3. Paste into your AI assistant chat window.
4. Add any context specific to your environment (system hostname, queue names, etc.).
